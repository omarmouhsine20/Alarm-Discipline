# ⏰ DisciplineAlarm

A smart alarm clock that makes you actually wake up: the sound won't stop until you type the required word.

🔗 **Live demo:** https://omarmouhsine20.github.io/Alarm-Discipline/

## ✨ Features
- Live current time and date display
- Set your alarm time
- Word challenge: type a random word to stop the alarm
- Modern dark design

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 🚀 How to Run
1. Download or clone the project
2. Open `index.html` in your browser
